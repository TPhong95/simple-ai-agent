This is a very simple agent if you can even call it that.  
  
It should under no circumstances be used as an out of the box solution.  
  
It's been used to explore what I can do with a LLM and how to create an agent from the api that I would get. 
The project used Openrouter's free models which will give about 50 request per day.   
  
This repo is a very simple version of an agent that can:  
- Look at your files
- Look at the directory structure
- Write to files
- Run python programs.  

I've used the course on boot.dev to help me with understand and explore this subject.  
https://www.boot.dev/courses/build-ai-agent-python  

And again under no circumstances should this repo be used as it's a very simple code so it doesn't have any security built in. It may under some circumstances change files in your computer outside the working directory if used.
